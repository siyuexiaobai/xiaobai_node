创建项目

创建流程

1.点击esp-idf的组件—>点击Advanced —>点击新项目向导

2.在vscode顶部弹出的选项中选择系统中安装的esp-idf组件，学习历程使用的5.5.4，由于之前电脑上在线安装了一个（D:/soft/Espressif……），在配置vscode的esp开发环境的时候又在线安装了一个(D:/esp……)，所以我选择开发环境安装的（两个环境都可使用）

3.创建项目：ESP-IDF Examples里面是官方提供的案例，就是创建案例项目之后烧录可以直接实现功能的；

ESP-IDF Templates里面就一个sample_project，它是创建一个空的项目模板，学习历程使用的是此模板，然后在右侧选择create project using template sample project

4.配置环境：

  1. 选择项目保存的文件目录，必须全英文目录，目录尽量不要出现字符及空格（必选）
  2. 选择主控芯片的型号，要与使用的芯片对应（后期可调）
  3. 选择烧录方式（后期可调）
  4. 选择烧录的com口（后期可调）
  5. 创建项目

芯片配置

打开底部菜单栏的SDK配置编辑器

1.在搜索框里搜索HZ然后将通过spi外扩的flash速度拉满（spi的速度），如果自己的板子没有外扩则不选，如果板子是n16r8之类的n16表示外扩16Mflash，r8表示外扩了8M的PSRam都可以进行此配置，在最下面将主频时钟拉到240MHz

2.搜索flash设置外扩的flash大小

3.搜索tick将时基设置成1000Hz，实现1ms一次

4.搜索PSRAM，将Support for external, SPI-connected RAM打钩（不打勾下面的配置不会出现），Mode (QUAD/OCT) of SPI RAM chip in use选择PSRAM的SPI连接方式QUAD是四线SPI Octal是八线SPI，最后在Set RAM clock speed配置PSRAM的时钟官方推荐时钟120Mhz，但80Mhz最稳定

参考esp组件库

在esp-idf组件库搜索ws2812，选择espressif/led_strip这个组件因为前面的espressif表示的是乐鑫官方开源的比较靠谱

点进组件库之后可以阅读说明文档阅读完后copyidf.py add-dependency “espressif/led_strip^3.0.3”到vscode
